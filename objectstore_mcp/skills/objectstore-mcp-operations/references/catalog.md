# Provider workflow catalog

Load only the workflow relevant to the current request.

- [objectstore-bucket-administration](../../objectstore-bucket-administration/WORKFLOW.md): Bucket administration through the objectstore-mcp MCP server: list stores and buckets, create, inspect and (gated) delete buckets, and manage bucket lifecycle rules and versioning on S3-compatible stores. Use when the agent must provision or audit buckets, discover which stores the caller may reach, set retention or expiry, or turn versioning on. Do NOT use for object reads and writes (objectstore-object-operations) or local file transfers (objectstore-data-transfer).
- [objectstore-business-asset-store](../../objectstore-business-asset-store/WORKFLOW.md): Run the business's durable asset store on objectstore-mcp: file generated creative outputs, video masters and social-media uploads under one key layout, tag each asset's stage, set retention, and hand an asset on to the file-share and social-scheduling steps with a presigned URL. Use when the agent must store, find, approve or hand off a business media asset. Do NOT use for generic object chores (objectstore-object-operations) or the file-share and social-scheduling steps themselves (their connectors' skills).
- [objectstore-data-transfer](../../objectstore-data-transfer/WORKFLOW.md): Move files between the server's local filesystem and object storage through the objectstore-mcp MCP server: upload or download one file, upload a directory under a prefix, or download every object under a prefix, all size- and count-capped. Use for staging, backups and restores that run on the server host. Do NOT use for in-memory object reads and writes (objectstore-object-operations) or bucket settings (objectstore-bucket-administration).
- [objectstore-object-operations](../../objectstore-object-operations/WORKFLOW.md): Object-level operations through the objectstore-mcp MCP server with one typed tool per operation: list, head, get, put, copy, move, delete (single or by prefix with a dry run), presigned URLs, user metadata and object tags. Use when the agent must read or write an object, page a bucket by prefix, mint a presigned URL, tag an object, or delete objects. Do NOT use for bucket provisioning, lifecycle or versioning (objectstore-bucket-administration) or moving local files (objectstore-data-transfer).
